# The Adventure of the Chestnut

A small point-and-click adventure about a chestnut that cracks open on a desk one night, opens its single eye and decides to get out of the house and grow into a tree. Seven chapters, one big house, and a cactus, a spider, a cat, a robot vacuum and a magpie along the way. Most puzzles have two solutions, nobody dies, nothing is unwinnable. All graphics are procedural vector drawing, all sound is synthesized in WebAudio — no assets, no dependencies, no build step.

A just-for-fun project, built with Claude Code (Fable model).

Play: open `docs/index.html` in a browser, or via [GitHub Pages](https://freeflyer.github.io/chestnut-adventure/). Mouse and touch supported, ten languages.
